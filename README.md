# Финальный проект — Titanic

## Структура проекта:

- `content/` содержит все файлы, которые используются для работы;
у меня здесь были папки для данных, предсказаний и моделей, но всё
это настраивается индивидуально в конфигурационном файле;
- `1_EDA_Titanic.ipynb` — ноутбук с анализом данных;
- `2_Feature_Engineering.ipynb` — подробный разбор фича-инженеринга и обработки данных;
- `config.py` — конфигурационный файл, из которого осуществляется настройка моделей и программы;
здесь находятся все пути к файлам, скоры с лидерборда Каггл и гиперпараметры к каждой модели;
- `data_handle.py` — каждая модель перед работой осуществляет предобработку данных с помощью метода, находящего здесь;
- `main.py` — главный файл, с которого начинается вся программа;
- `model_*.py` — содержит однотипные модели;
- `requirements.txt` — необходимые библиотеки для работы программы; загружаются с помощью `pip3 install -r requirements.txt`

---

Изначально программа тренирует все модели, считает для них CV, CV STD и предсказания на тестовых данных. В конце выдаёт таблицу с метриками каждой модели.

Обучение каждой модели можно отключить в конфигурационном файле. Если обучение отключено, модель считывает сохранённую модель и просто делает предсказания на тестовых данных.

Гиперпараметры моделей максимально вынесены в конфигурационный файл. Новые гиперпараметры также добавляются через `config.py`, добавлять их в код не требуется.

Файлы для хранения моделей захардкожены и имеются строгие названия:
- Логистическая регрессия — `logreg_model.joblib`;
- Логистическая регрессия с L1-регуляризацией — `logreg_l1_model.joblib`;
- Логистическая регрессия с L2-регуляризацией — `logreg_l2_model.joblib`;
- Логистическая регрессия с ElasticNet-регуляризацией — `logreg_en_model.joblib`;
- KNN — `knn_model.joblib`;
- Дерево решений — `dt_model.joblib`;
- Случайный лес — `rf_model.joblib`;
- CatBoost — `catboost_model.cbm`;
- LightGBM — `lightgbm.model.txt`;
- XGBoost — `xgboost_model.json`;
- NeuralNetwork — `nn_model.pt`;
- Bagging — `bagging_model.joblib`;
- Stacking через линейную регрессию — `stacking_model.joblib`;
- Stacking через ridge-регрессию — `stacking_l2_model.joblib`.

---

Для запуска программы достаточно настроить файл `config.py` и запустить `main.py`.\
Перед запуском обязательно доустанавливать все необходимые библиотеки: `pip3 install -r requirements.txt`.
